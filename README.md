# دستیار اقساط

نسخه 1.0 یک اپ ساده و آفلاین برای Android 12+ است.

امکانات:
- ثبت قسط با عنوان، مبلغ، تعداد، روز سررسید و تاریخ اولین سررسید
- نمایش داشبورد اقساط فعال و مانده تقریبی
- ثبت پرداخت ماهانه با یک دکمه
- محاسبه خودکار قسط بعدی
- یادآوری اعلان 3 روز قبل از سررسید
- ذخیره اطلاعات داخل خود گوشی
- بازیابی زمان‌بندی اعلان‌ها بعد از روشن شدن مجدد گوشی

نسخه فعلی عمداً به حساب بانکی، رمز کارت یا اینترنت نیاز ندارد.
قابلیت خواندن پیامک بانکی و تشخیص موجودی در نسخه بعدی باید با مجوزهای اندروید و قالب پیامک بانک‌ها جداگانه پیاده‌سازی شود.

برای ساخت APK:
1. پروژه را در Android Studio باز کنید.
2. Gradle Sync را اجرا کنید.
3. از Build > Build APK(s) استفاده کنید.
حداقل Android: 12 (API 31)
Target SDK: 35
